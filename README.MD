## Онлайн-магазин на Django

### В репозитории происходит разработка бэкенда для онлайн магазина

## Установка и использование:
1) Клонируйте репозиторий к себе на компьютер с помощью команды `git clone`
2) Проект использует poetry, поэтому для использования проекта установите его. И установите зависимости с помощью `poetry install`

# Функционал проекта:
Этот проект разработан с использованием **Django** и направлен на создание веб-приложения онлайн магазина.

На данный момент проект находится на ранней стадии разработки и проектирования, поэтому описание на данный момент отсутствует.
Совсем скоро здесь появится детальная информация о функционале, архитектуре и процессе установки.

## Тесты
Для всех модулей проекта были написаны тесты с помощью pytest
